# Using the app

The manual for the drawing app, in the order it reads best: the tools first,
then the gestures that make drawing quick, then everything that edits,
arranges and saves what was drawn. For the essentials alone, start with the
[Quickstart](../../../QUICKSTART.md); for every key on one page, the
[Cheatsheet](../../../CHEATSHEET.md).

## Built to be calm

- Calm, accessible UI (WCAG-AA contrast, reduced-motion support — the
  page-turn animation and the symmetry-guide fade both stand still when the
  OS asks for reduced motion).
