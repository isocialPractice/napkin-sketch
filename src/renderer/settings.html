Verbose Settings

Everything here persists across launches. The in-app panel (Ctrl+,) shows the same Quick Settings for fast access while drawing.

Pan & Zoom

Hold Alt and scroll the mouse wheel to zoom. By default scroll up zooms in and scroll down zooms out. An Alt used to zoom never hands the keyboard to the menu bar.

Scroll the wheel to pan vertically; hold Ctrl + Shift to pan horizontally.

Quick Features

Time allowed to type a value after pressing W (width) or Q (opacity).

Hold Shift while drawing to snap the stroke to the nearest endpoint of an existing stroke within the sensitivity radius. A straight line's end and a quick curve's far end snap without Shift.

When on, a stroke that snaps onto another stroke's endpoint (same tool and color) merges with it into one stroke.

Sketch Support

Draws the grey triangle mesh over art being bent with Mesh Warp. Off, only the pins show, so the bend can be judged on the art alone. The same switch is in Quick Settings.

How far from a mark's ink a click with the Select tool (V) may land and still pick it, in screen pixels, so it reaches as far at every zoom. A click on the ink itself always picks the mark on top.

Grab radius for anchor points, handles, and paths with the Direct Select tool (A), in screen pixels. The Vector Path tool's anchors and its closing click use it too.

Radius the eyedropper (I) averages when picking a color from the canvas.

How closely a Brush, Marker or Copic stroke's curves follow what you drew, in screen pixels. A stroke is kept as a few Bézier anchors fitted to its samples: smaller keeps more of the hand's detail, in more anchors; larger smooths more, in fewer.

Draws the dashed blue outline around selected elements, and toggles from anywhere with Ctrl/Cmd + H. On by default. Switched off they stay selected and still move, copy and export the same way, and the layers panel still shows what is selected - only the outline on the canvas goes, so the drawing can be judged with something selected. The Move palette carries the same switch, beside its live preview.

Puts the Transform box, with its handles, up by itself around whatever the Select tool selects, as a vector editor's bounding box is, and takes it down when nothing is selected. On by default. Escape or Ctrl/Cmd + T put an automatic box away for that selection; the next selection brings it back. Off, the box is put up by hand, as before. A 3D mark keeps its gumball either way.

A transform takes a mark's line weight and its effects with it, as a vector editor's setting of the name does: scaling it scales its width and its effects, turning it turns a shadow's offset and a bevel's light, and mirroring it flips them. On by default. Off, they stay as they were whatever the mark goes through.

A mark's bounds take in what its effects paint outside it - a shadow, a glow, an outer bevel - so its selection box, the Transform Box and Align go round them, and a click on its shadow picks it. Off by default: the bounds are the mark's own, as a vector editor's are.

A mark built in 3D, selected alone, shows the gumball: arrows, squares, arcs and boxes on the canvas that move it, turn it and scale it in depth, in X red, Y green and Z blue. On by default. Off, the 3D Options panel is the only control, and the Transform Box edits the shape the 3D is built from, as it does with the gumball up.

Type

The Type panel comes up by itself while the Text tool is in hand and a text is selected or being typed, and goes when another tool is chosen. A panel opened from the View menu stays. On by default.

The family a new text is set in. The Type panel sets it to the last font chosen there; empty, new text takes the system's interface font.

What is typed in a new text is Markdown, shown as it renders: a heading, a list, a quote, code. Type > Markdown Flow turns it on and off for a text. Off by default.

The colors Clean Language Accents give code: Napkin Light on a light page and Napkin Dark on a dark one, or one of them always. Each color stands out clearly from its theme's code shade.

A Markdown code block that names no language is colored as the installed language it reads most like. Off by default, since it guesses. Type > Clean Language Accents > Languages installs more languages.

A PDF draws each letter as its font's own outline, so the page looks as it does here on any computer. Off, text is set in Helvetica, which a PDF reader can select and search. A text whose font cannot be read is set in Helvetica either way. On by default.

Quick Settings

Mirrors the in-app Quick Settings panel (Ctrl+,); both edit the same persisted values.

Copic Marker

Hold the hold key still for the hold time, with a drawing tool in hand, to show the nib indicator, then hold a rotate key to turn the broad nib. Moving the pointer, pressing or typing another key during the hold cancels it. While active, the stroke width is scaled by the width multiplier (restored on release). The three keys must differ; a clashing pick is reassigned automatically.

Automate

Track History is off, so nothing is recorded.

While Track History is on, every step of the drawing's history - a stroke, a command, an undo - is kept, up to the limit, and the oldest goes first. Automate > Generate Script > From Session History writes the steps as a script. A new or opened document starts a new history, and turning tracking off clears it.

Extras

A report lists what an action could not do, in the bottom-right corner. It stays put while the pointer or the keyboard is on it, or while its details are open. At 0 it stays until it is closed.

A napkin wipes over a Wipe Stacks result for a quarter of a second. Off - or with the system asking for reduced motion - the result shows at once.
