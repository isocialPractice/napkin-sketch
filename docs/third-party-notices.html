Clean Language Accents read code with highlight.js (highlightjs/highlight.js). esbuild bundles its core and its 36 common languages into dist/ - into napkin-sketch/markdown, the app's renderer, the command line and napkin-sketch/node - and each of its other languages into a file of its own in dist/renderer/accents/, which the app loads when that language is turned on. None of those files keeps highlight.js's own comments; this is their notice.

The en-US hyphenation patterns#

Text hyphenates by Liang's algorithm over the en-US patterns of hyph-utf8's hyph-en-us (TeX Live's ushyphmax): Liang's patterns from Knuth's hyphen.tex with Gerard D.C. Kuiken's additions, and plain.tex's exceptions. They are src/core/type/hyphenation/en-us.json, bundled into dist/, which carries this notice as its file did, and the API exports it as HYPHENATION_NOTICE.

In the repository only#

The test fonts#

test/fonts/napkin-test-sans.ttf and test/fonts/napkin-test-cff.otf, the fonts the tests read glyph outlines from, are subsets of Liberation Sans 2.1.5 and of Miriam Libre 1.000, renamed, as the SIL Open Font License 1.1 asks of a modified font. The license, with both originals' copyright notices, is test/fonts/OFL.txt. They are test fixtures: neither the npm package nor the desktop app carries them.
